# Teal VPN Homebrew tap

Install [Teal VPN](https://tealvpn.com/mac) on a Mac (macOS 13 Ventura or newer, Apple silicon and Intel) with Homebrew:

```sh
brew install --cask tealvpn/tap/teal-vpn
```

Update: `brew upgrade --cask teal-vpn`. Remove: `brew uninstall --cask teal-vpn`.

The cask downloads the same signed and notarised disk image as the download button on [tealvpn.com/mac](https://tealvpn.com/mac) (`download.tealvpn.com/mac/TealVPN-<version>-<build>.dmg`, checksum pinned). The app is also published as a [GitHub release](https://github.com/tealvpn/mac/releases).

Teal VPN is free with 500 MB a day, no card and no ads; Teal Pro adds unlimited data and every location. Made by Fxolio LLC. Support: support@tealvpn.com.
